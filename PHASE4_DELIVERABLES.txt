      → Verify audit chain integrity

🦀 RUST CAPSULE ARCHITECTURE

Entry Points (WASM exports):

  extern "C" fn asguard_version() -> *const u8
    Returns: "asguard-capsule/0.1.0\0"

  extern "C" fn asguard_init_capsule(config_json, len) -> i32
    Loads configuration and initializes components
    Returns: 0 (success) or -1 (error)

  extern "C" fn asguard_evaluate_tool_call(
    agent_id, agent_id_len,
    tool_name, tool_name_len,
    params_json, params_len
  ) -> i32
    Evaluates a tool call for anomalies
    Returns: 0 (allow) | 1 (warn) | 2 (halt/HITL)

Policy Structure:
  {
    "max_auto_trade_usd": 50000,
    "strict_anomaly_detection": true,
    "device_ip_lock": true,
    "remote_trigger_protection": true,
    "active_llm_engine": "ollama"
  }

Evaluation Scoring:
  Rule                    Max Points   Conditions
  ─────────────────────────────────────────────────
  Budget Overrun          +50          amount > limit
  IP Breach               +40          new IP detected
  Device Breach           +35          new device detected
  Frequency Spike         +30          >300% baseline
  Unverified Contract     +45          not whitelisted
  ─────────────────────────────────────────────────
  TOTAL                   0-100        (capped)

Action Determination:
  0-39:   silent_pass (allow silently)

📋 INSTALLATION PROCESS
════════════════════════════════════════════════════════════════════════════

Automated Setup (Recommended):

  $ cd /path/to/asguard
  $ chmod +x install.sh
  $ ./install.sh

  This automatically:
  1. Checks all dependencies
  2. Creates ~/.astrid/ directory
  3. Initializes policy file with defaults
  4. Installs Node.js dependencies
  5. Compiles Rust capsule
  6. Creates /usr/local/bin/asguard symlink
  7. Shows verification steps

Manual Setup:

  $ mkdir -p ~/.astrid
  $ cat > ~/.astrid/asguard_policy.json << 'EOF'
  {
    "max_auto_trade_usd": 50000,
    "strict_anomaly_detection": true,
    "device_ip_lock": true,
    "remote_trigger_protection": true,
    "active_llm_engine": "ollama"
  }
  EOF
  $ npm install
  $ cd capsule && cargo build --release && cd ..

Verification:

  $ asguard status
  
  Expected Output:
  ✓ Backend is running (http://localhost:8080)
  ✓ Frontend is running (http://localhost:3000)
  ✓ Policy file exists: ~/.astrid/asguard_policy.json
  ✓ Audit chain: 0 entries
